Key Ideas for Today

  1. An sf object is a data frame plus geometries.
  2. Unary functions measure or reshape a geometry.
  3. Binary predicates test how two geometries relate.
  4. A spatial join matches rows by location.

Concept Acquisition

  1. Spatial data come from R packages and web APIs, shapefiles, GeoJSON, and KML.
  2. An sf object is a data frame of attributes plus a geometry column (an sfc) built from individual st_ geometries and a CRS.
  3. dplyr verbs work on the attributes of an sf object and carry the geometry along; summarize() also combines the geometries.
  4. Unary measures (dimension, area, length) return a number for each geometry; unary transformers (centroid, jitter, buffer) return a new geometry.
  5. A binary predicate such as within tests how two geometries relate; a spatial join uses one to match rows, keeping (left) or dropping (inner) unmatched rows.

Tool Acquisition

  1. st_read(), st_geometry(), and base plot() / points().
  2. st_point(), st_polygon(), st_sfc(), and st_sf().
  3. st_dimension(), st_area(), st_length(), st_centroid(), st_jitter(), and st_buffer().
  4. st_within() and st_join() with join = and left =.

(Last Time) Simple Feature Object:

Features: “things” or objects that have a spatial location or extent; they may be physical objects like a building, or social conventions like a political state

Feature geometry: the spatial properties (location or extent) of a feature, and can be described by a point, a point set, a polygon, etc.

Feature attributes: other non-spatial properties measured on the feature (e.g. color, name, landtype)

Guess the Metaphor

A spatial join is like the pirate islands: the islands are polygons and the ships are points. To learn whose waters each ship sails in, you match them by location, not by a shared key, and a ship out in open water finds no island at all.
