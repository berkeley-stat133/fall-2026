Code Completion

A feature of an IDE that sends the code around your cursor to an LLM and shows the predicted next tokens as a suggestion, which you can accept or ignore.

In Positron:

  • Suggestions appear in grey as you type.
  • Tab accepts, Esc dismisses, or just keep typing.
  • Works in R scripts, Quarto documents, and the console.

Before you press Tab

A suggestion is the likely next code. Whether it’s the right next code depends on what you’re trying to do.

Stateless

A server is stateless if it keeps nothing from one request to the next. An LLM API is stateless: to continue a conversation, the client sends the whole conversation again.

Context

Context

All of the text that a model reads when it generates a response: the instructions, the earlier turns of the conversation, and any code, data, or documentation sent along with the prompt.

The model has two sources for an answer:

  1. what it learned in training (fixed, and the same for everyone);
  2. what is in the context (chosen by the client, for each request).

A question, with no instructions

plain <- chat_claude(model = "claude-haiku-5-5")
plain$chat(
  "How do I find the mean body mass for each species of penguin in R?"
)
The easiest way is with `dplyr`:

```r
penguins %>%
  group_by(species) %>%
  summarise(mean_body_mass = mean(body_mass_g, na.rm = TRUE))
```

**Base R alternative**:

```r
tapply(penguins$body_mass_g, penguins$species, mean, na.rm = TRUE)
```

The same question, with a system prompt

tutor <- chat_claude(
  model = "claude-haiku-5-5",
  system_prompt = "You are a tutor for Stat 133. Students use the
    tidyverse and the native pipe. Never write the code for them.
    Reply in two sentences: name one function to look at, then ask
    one question."
)
tutor$chat(
  "How do I find the mean body mass for each species of penguin in R?"
)
Look at `group_by()` and `summarize()` from dplyr, since grouping by
species and then summarizing the mean of body mass is the key idea. What
do you think the grouping variable should be called in the penguins
dataset, and which column holds body mass?

System Prompt

Instructions that the client places at the start of the context and sends with every request. It sets the model’s role, its conventions, and what it should and shouldn’t do.

{
  "model": "claude-haiku-5-5",
  "system": "You are a tutor for Stat 133. Students use the ...",
  "messages": [
    {"role": "user",
     "content": "How do I find the mean body mass for each ..."}
  ]
}

Guess the Metaphor

An LLM is like a judge: it rules only on what’s entered into the record (the context). At every hearing, the clerk reads the whole record aloud again, starting with the law posted above the bench (the system prompt).
