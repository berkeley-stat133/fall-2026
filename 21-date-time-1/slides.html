Key Ideas for Today

  1. A date-time counts seconds since 1970 (Unix time).
  2. Parsing turns text into a date-time.
  3. Getters and setters read and change its parts.
  4. Some parts, like months, are circular.

Concept Acquisition

  1. Computers store a date-time as the number of seconds since the Unix epoch, midnight UTC on 1 January 1970.
  2. A POSIXct vector is a double vector with a class, so it prints as a legible date-time but still supports arithmetic, rounding, and other formats.
  3. A Date vector is a simpler class that stores dates without times.
  4. Date-time strings come in many formats; parsing one requires knowing the order of its components.
  5. The components of a date-time (year, month, weekday, hour) can be extracted and changed in place.
  6. Some components are circular, so averaging them as plain numbers gives nonsense; average the date-times instead.

Tool Acquisition

  1. Sys.time(), as.POSIXct() (with tz and format), as.Date(), and format().
  2. lubridate parsers such as mdy_hm() and dmy_hm().
  3. Getters and setters: year(), month(), week(), day(), wday(label =, abbr =), hour().
  4. make_datetime().

POSIXct

POSIXct (Portable Operating System Interface Calendar Time) is an atomic vector to store date-times that is built on top of a double vector.

now <- Sys.time()
now
[1] "2026-10-23 15:43:29 UTC"
class(now)
[1] "POSIXct" "POSIXt"

Start off with reminder about factors: a integer vector with the factor class that allows it to store the levels look up table.

Why not just use a double vector?

# it prints as a legible string
now
[1] "2026-10-23 15:43:29 UTC"
# while respecting artithmetic
now + 1
[1] "2026-10-23 15:43:30 UTC"
# and other sensible operations
round(now, units = "hours")
[1] "2026-10-23 16:00:00 UTC"
# and makes it easy to use other formats
format(now, "%m/%d/%y")
[1] "10/23/26"

Date

A simpler vector than POSIXct that stores date data without times. Created with as.Date().

halloween <- as.Date("2000-10-31")
class(halloween)
[1] "Date"
typeof(halloween)
[1] "double"
halloween
[1] "2000-10-31"

lubridate() has many functions that can parse the year (y), month (m), day (d), hour (h), minute (m), and second (s) components of a date-time string.

library(lubridate)

[1] "1970-01-01 00:01:00 UTC"
dmy_hm("1-1-1970 00:01")

Guess the Metaphor

A date-time is like a giant sundial: underneath it’s a single measurement, how far the shadow has travelled from a fixed origin, but we read it off the dial as hours and days. And like the dial, some parts wrap around: December sits right next to January.
