Structure of an R function

Function

A named procedure that takes arguments (inputs) and returns a value. Arguments can be supplied by position or by name, and some have default values.

Live-code the one at a time. Draw out the anatomy on the chalkboard: function name, then arguments inside ().

  • log(10) uses the default base e.
  • Naming an argument (base = 10) is unambiguous.
  • By position, the second argument is base, so log(10, 5) and log(5, 10) differ.
  • When you name every argument, order stops mattering: log(base = 5, x = 10).
  • You can learn more about the function by pulling up it’s help file with ?
log(10)
log(10, base = 10)
?log
log(10, base = 5)
log(10, 5)
log(5, 10)
log(base = 5, x = 10)

Creating objects

Object

A value saved into your environment under a name, using the assignment arrow <-. Calling the name on its own prints the value.

Creating objects

a <- 3 + 5      # save the result into an object named a
print(a)
a               # calling an object invokes print()
a + 2
a <- a + 2      # overwrite a with a new value
ls()            # list objects in environment

Emphasize that <- does not print anything — the value is stored. Show the object appearing in the Environment. The last line is worth pausing on: the right side is computed first, then assigned back to a.

The R environment

Environment

The collection of all objects currently defined in your R session, each stored under its name. Assignment adds or updates an object in the environment; ls() lists what it contains.

Tie this back to the previous slide: the objects created with <- all live in the environment. Show the Environment pane so students can see the names and values accumulating as they run code.

R on the file system

From the shell to R

Last time we moved around the file system at the command line. An R session has the same idea of a working directory — and its own functions to get around.

Task Shell R
Where am I? pwd getwd()
What’s around me? ls list.files()
Change where I am cd setwd()
See a file’s contents cat readLines()

On the board, sketch the file system tree and draw two boxes next to it, one labelled “shell” and one labelled “R”. Both have a working directory that you can move. Then live-code the R column.

Where am I? What’s around me?

getwd()
ls()            # careful: lists objects, not files!
list.files()
setwd()
system("tree .")

The gotcha: ls() in R lists objects in your environment, not files on disk — a false friend from the shell. list.files() is the file lister. system("tree .") shells out to draw the tree we studied last time.

Warnings and errors

Warning

A message telling you something might be off. The code still runs and returns a value.

Error

A message telling you the code could not run. No value is returned.

Warnings and errors

Case study: distances traveled

How far did we travel this summer?

Recall the second question on your index card: the farthest you were from Cal this summer, in miles.

All of those values have been pulled out of the individual files and stacked into one:

find . -type f -name "*.txt" -print0 \
  | xargs -0 awk 'FNR==2 && /^[0-9,]+$/' \
  > combined_output.txt

This connects today’s tools back to the index-card data from lectures 1–2. Don’t dwell on the find | xargs | awk incantation — just note that the command line let us grab the second line of every file and combine them. This is why the command line is worth knowing.

Reading the distances into R

readLines("combined_output.txt")
distances <- readLines("combined_output.txt")

mean(distances)      # whoops — a mean of character strings

readLines() gives us a value per line, but each is a character string. mean() on characters returns NA with a warning. Ask the students what went wrong before revealing the fix.

Converting and summarizing

distances <- as.numeric(distances)   # text -> numbers
mean(distances)
sd(distances)
summary(distances)

as.numeric() coerces the strings to numbers; now the summaries work. Read summary() together — min, quartiles, median, mean, max — as a first look at the distribution. If any value fails to convert it becomes NA; watch for that.
