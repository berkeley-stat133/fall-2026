Key Ideas for Today

  2. Explanatory plots tell one story to one audience.

  4. Themes and set aesthetics polish the look.

Concept Acquisition

  1. EDA is for the analyst: its goal is to uncover structure and generate new questions, guided by a set of common exploratory questions.
  2. Exploratory and explanatory visualizations differ in audience, goal, and level of polish.
  3. Axis limits, non-linear scales, and the ordering of categories decide which comparisons a plot makes easy.
  4. A theme controls the non-data elements of a plot; theme() tweaks the current theme, so add it after a complete theme.

Tool Acquisition

  1. dim(), sapply(df, class), and sum() / mean() of is.na() for a first look.
  2. geom_bar(), geom_col(), and count().
  3. labs() for titles, axis labels, and legends.
  4. lims(), scale_x_log10(), scale_y_sqrt(), fct_infreq(), and fct_reorder().
  5. theme_gray() / theme_bw() / theme_minimal(), theme(axis.text.x = element_text(...)), and setting color / fill.

Clarify with Labels

Annotate plot showing the following labels: x, y, color, main, subtitle.

Labels with labs()

The labels on the plot can refer to many different places where text is added to describe what is plotted.

  • title
  • subtitle
  • x-axis
  • y-axis
  • legends

In ggplot2, these are arguments to a labs() layer.

  • title
  • subtitle
  • color
  • fill
  • size
  • shape

penguins |>
  ggplot(aes(x = bill_length_mm,
             y = flipper_length_mm,
             color = species)) +
  geom_point()

penguins |>
  ggplot(aes(x = bill_length_mm,
             y = flipper_length_mm,
             color = species)) +
  geom_point() +
  labs(title = "Penguin size differs by island",
       x = "Bill Length (mm)",
       y = "Bill Depth (mm)",
       color = "Species")

Limits and Scales

Emphasize certain comparisons (and occlude others) by altering the limits of the axes to include a relevant baseline and by using non-linear scales.

  • lims()
  • scale_x_log10()
  • scale_y_log10()
  • General scale_ family of layers

Polish Your Look

Return to the previous slide and note the aspects of the plot that aren’t data and aren’t labels: the grid lines, the axis tick marks, the font, the font size, the background. These are all elements of the theme.

Theme

A set of visual design choices for the plot on things like the background, the gridlines, the axes, the tick marks, and the fonts.

Some ggplot2 themes (each one can be added as layer)

  • theme_gray(): the default
  • theme_bw()
  • theme_minimal()
