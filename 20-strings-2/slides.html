Concept Acquisition

  1. A character class matches any one character from a set; ^ at its start negates it and - expresses a range.
  2. Shortcut classes (\d, \s, \w and their capitals) name common sets, and need a second backslash inside an R string.
  3. Anchors (^, $) match positions, not characters, so they pin a pattern to the start or end of a string.
  4. Parentheses group characters so a quantifier applies to the whole group, and | matches one pattern or another; grouping limits how far an alternation reaches.

Tool Acquisition

  1. Regex syntax: ^, $, [...], [^...], [a-z], \\d, \\s, \\w, (), and |.
  2. str_view(..., match = NA), str_count(), and str_extract() from stringr.
  3. A regex tester such as https://regexr.com/.

More Character Classes

Ranges and Negation

  • Special characters in a set:
    • ^ at the start negates the set.
    • - expresses a range.
x <- "abcd ABCD 12345 -!@#%."
str_view(x, "[a-z]+")
[1] │ <abcd> ABCD 12345 -!@#%.
str_view(x, "[^a-z0-9]+")
[1] │ abcd< ABCD >12345< -!@#%.>

On the pinned board: “^ inside [ ] = not; ^ outside = start.” Return to it at Anchors.

Shortcut Class

A character class with a built-in name, such as \d for any digit.

  • \d matches any digit;
  • \D matches anything that isn’t a digit.
  • \s matches any whitespace (e.g., space, tab, newline);
  • \S matches anything that isn’t whitespace.
  • \w matches any “word” character, i.e. letters, numbers, and underscores;
  • \W matches any “non-word” character.

Note: These all have to be escaped when forming a string to express the pattern.

Shortcut classes

x <- "abcd ABCD 12345 -!@#%."
str_view(x, "\\d+")
[1] │ abcd ABCD <12345> -!@#%.
str_view(x, "\\D+")
[1] │ <abcd ABCD >12345< -!@#%.>
str_view(x, "\\s+")
[1] │ abcd< >ABCD< >12345< >-!@#%.
str_view(x, "\\S+")
[1] │ <abcd> <ABCD> <12345> <-!@#%.>

Guess the Metaphor

A regular expression is like a wanted poster on the thief guild’s wall: it describes a pattern (red cloak, one or more scars, last seen at the docks). Anchors say where to look, classes list the looks that count.
